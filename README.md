# Muhammad Sohail — Personal Portfolio

A responsive personal portfolio website built with **HTML5 and CSS3** to showcase my professional profile, education, technical skills, development projects, and contact information.

## Overview

This is a static portfolio website designed to present my background and development work in a clean and responsive interface.

The website does not use a backend framework, database, or server-side application logic. All page content and layout are implemented using HTML and CSS.

## Technology Stack

* HTML5
* CSS3
* SVG
* Google Fonts

### Frontend Techniques

* Semantic HTML structure
* CSS Grid
* CSS Flexbox
* Responsive design
* CSS custom properties
* Media queries
* Responsive typography
* Sticky navigation
* Mobile navigation
* Card-based layouts
* CSS transitions and hover states
* Dark-mode support using `prefers-color-scheme`

## Local Development

Because this is a static website, no Python, Django, database, or backend server is required.

Clone the repository:

```bash
git clone <your-portfolio-repository-url>
cd <your-portfolio-directory>
```

The website can be opened directly by opening:

```text
index.html
```

For a local development server, Python can also be used:

```bash
python -m http.server 8000
```

Then visit:

```text
http://127.0.0.1:8000/
```
